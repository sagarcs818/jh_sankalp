# 🚀 JH-SANKALP

### Smart India Hackathon | Smart Societal Challenge & Project Lifecycle Management Ecosystem

**JH-SANKALP** is an enterprise-grade, full-stack collaboration platform designed to connect **Citizens, Government Departments, Academic Institutions, and Industry CSR Partners** on a unified ecosystem.

The platform enables stakeholders to **report, track, analyze, prioritize, match, and resolve societal challenges** efficiently throughout the complete project lifecycle.

Built for the **Smart India Hackathon (SIH)**, JH-SANKALP addresses the need for integrated project lifecycle management and ecosystem-wide collaboration.

# 🚀 Local Installation & Setup

## 📋 Prerequisites

Make sure the following software is installed:

* **Python** v3.10 or higher
* **Node.js** v18 or higher
* **npm**
* **Git**
* **PostgreSQL** *(Optional for local development, highly recommended)*

---

# 1️⃣ Clone the Repository

```bash
git clone https://github.com/sagarcs818/jh_sankalp.git
cd jh_sankalp
```

---

# 2️⃣ Configure Environment Variables (`.env`)

Create a `.env` file in the root directory.

> ⚠️ **Important:** Do not commit your `.env` file to Git.

```env
# Core Django Settings
SECRET_KEY=your_super_secret_key_here
DEBUG=True

# Database Configuration
# Uncomment the following variables to use PostgreSQL
# DB_NAME=jh_sankalp_db
# DB_USER=postgres
# DB_PASSWORD=your_password
# DB_HOST=localhost
# DB_PORT=5432

# Hybrid Security Clearance Codes
GOV_CLEARANCE_CODE=gov123
ADMIN_CLEARANCE_CODE=admin123
```

---

# 3️⃣ Backend Setup — Django

Open your terminal and run the following commands.

## Create and Activate Virtual Environment

```bash
python -m venv venv
```

### Windows

```bash
venv\Scripts\activate
```

### macOS / Linux

```bash
source venv/bin/activate
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Run Migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

## Create a Superuser

Create a System Admin account:

```bash
python manage.py createsuperuser
```

## Start the Django Server

```bash
python manage.py runserver
```

✅ **Backend:** `http://127.0.0.1:8000/`

---

# 4️⃣ Frontend Setup — React / Vite

Open a **new terminal window** and keep the Django backend running.

Navigate to the frontend directory:

```bash
cd frontend
```

Install Node dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

✅ **Frontend:** `http://localhost:5173`

# 🔒 Enterprise Hybrid Security

JH-SANKALP implements an **Enterprise Hybrid Security System** for high-level registrations such as **Government Officials and System Administrators**.

## 1. Dynamic Database Check

The system first checks the `SystemSetting` database for live clearance codes.

These codes can be updated by the **System Admin** directly from the React dashboard.

## 2. Environment Fallback

If the database is unavailable, wiped, or undergoing migration, the system falls back to the default clearance codes stored in the `.env` file:

```env
GOV_CLEARANCE_CODE=gov123
ADMIN_CLEARANCE_CODE=admin123
```

This architecture provides operational flexibility while maintaining a fallback authentication mechanism.

> ⚠️ **Production Security Note:** Replace development clearance codes with strong, environment-specific secrets before deploying the application to production.
